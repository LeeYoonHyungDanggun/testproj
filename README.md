# Flutter Hello World

기본적인 Flutter Hello World 프로젝트입니다.

## 시작하기

이 프로젝트는 Flutter 애플리케이션의 기본 구조를 보여줍니다.

### 필수 요구사항

- Flutter SDK 3.0.0 이상
- Dart SDK

### 설치 및 실행

1. 종속성 설치:
```bash
flutter pub get
```

2. 애플리케이션 실행:
```bash
flutter run
```

## 프로젝트 구조

- `lib/main.dart`: 애플리케이션의 메인 진입점
- `pubspec.yaml`: 프로젝트 설정 및 종속성 관리

## 기능

- 화면 중앙에 "Hello World!" 메시지 표시
- Material Design 3 테마 적용
- 기본 앱바와 레이아웃 구조
